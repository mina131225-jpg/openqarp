# SaaS 店舗オンボーディング（PoC・正直版）

マルチテナント隔離の前提: **A店の店長は B店のスタッフ／時給／給与／予算を見られない・触れない**。  
データは `stores.json` 上で `store_id` 単位に分かれ、LINE 操作は常に `user_index` → 所属店舗のみを参照します。

## PoC の現実（共有公式アカウント）

| 今（PoC） | 将来（本番 SaaS） |
|-----------|-------------------|
| **1つの shared Official Account** ＋ **店舗ごと招待コード** | 店舗ごと（または加盟店ごと）に Messaging API チャネル |
| スタッフは同じ友だち追加 URL／QR → 「登録 CODE」で店舗に紐付け | 友だち追加時点でチャネル＝店舗が分離 |
| 店長は「店舗作成 店名」で自分の店舗＋招待コードを発行 | 管理コンソール／課金テナントと OA を紐付け |

PoC でも **アプリ層の店舗隔離は必須**（本ディレクトリの `stores.py` / webhook が担当）。  
チャネル共有は「届くトークが同じ箱」なだけで、給与・スタッフ名簿は店舗境界を越えない実装にしています。

## 3分オンボーディング（タップ中心）

1. 友だち追加（`https://line.me/R/ti/p/@813jdxwv`）→ ウェルカムに［お店を始める（店長）］［スタッフとして参加］
2. ［お店を始める（店長）］→ 店舗名を1回だけ入力 → 店舗作成（セットアップ 1/4）
3. ［上記を確認しました］→［同意する］→ 14日間無料トライアル開始（2/4）
4. すぐ「スタッフを招待」: 転送用テキスト（友だち追加 URL＋招待コード＋1行手順）、
   ［LINEで招待を送る］（`https://line.me/R/share?text=…`）、［QRコードを表示］（画像メッセージ）、
   ［招待ページを開く］（`/invite/<code>`）、［他の店長に紹介］
5. ［サンプルでシフトを作ってみる］→ 実スタッフ2名未満ならデモ4名（サンプル佐藤ほか）で3案。
   【サンプル】表記・確定ボタンなし・pending/確定/通知には一切書き込まない（4/4）
6. いつでも「続きから」（quick reply／テキスト）で次のステップへ

スタッフ: ［スタッフとして参加］→ 招待コード → 名前 → 店長へ「太郎さんが参加しました（3/5名）」を push。
従来の「登録 CODE 名前」でも同じ通知が飛びます。

招待ページ `/invite/<code>` と `/invite/<code>/qr.png` は店舗名と招待コードだけを表示します
（スタッフ名・時給・userId・store_id は出しません。店舗名は HTML エスケープ）。
QR の中身は公式アカウントの友だち追加 URL（トンネル URL が変わっても印刷物が無効にならない）。
LINE の画像メッセージには公開 HTTPS が必要なので `PUBLIC_BASE_URL` をトンネル URL に設定してください。
紹介: ［他の店長に紹介］で店舗データを含まない紹介文＋店舗ごとの紹介コード（`R` + 5文字）。
紹介された店長は「紹介コード RXXXXX」で `referred_by` に記録されます。

## 店長の手順（LINE）

1. **公式アカウントを友だち追加**（共有 OA の友だち追加 URL／QR）
2. **店舗を開設**  
   ```
   店舗作成 青山店
   ```  
   → 返信に `招待コード`（例: `K7MP2Q`）と店舗IDが返る。あなたが店長になる。
3. **スタッフを招待**  
   - 友だち追加 URL／QR を渡す  
   - あわせて招待コードを口頭／紙／チャットで渡す  
   - スタッフは: `登録 K7MP2Q 太郎`
4. **時給・交通費・予算**（店長コマンド）  
   ```
   時給 太郎 1200
   交通費 太郎 500
   人件費予算 200000
   ```
5. **シフト／給与**  
   ```
   シフト3案作って
   確定 希望
   給与 今月
   給与確定 9月
   ```

既存デモ店舗に参加する場合のみ: `店長登録 DEMO01`  
※ すでに別店舗の店長なら、他店への店長登録は **拒否**（店舗隔離）。

## スタッフの手順

1. 公式を友だち追加  
2. `登録 <招待コード> <表示名>`  
3. `希望休 日曜` / `自分のシフト` / （自分の）`給与 今月`

スタッフは **同僚の時給・給与明細を見られません**（店長のみ）。

## 隔離の要点（実装）

- すべての読取／書込は `get_store_for_user(userId)` の `store_id` にスコープ
- 人名解決（`find_worker_id`）も **その店舗の members のみ**
- `GET /stores` は全店舗一覧のため **`LINE_STORES_ADMIN_TOKEN` + `X-Admin-Token` 必須**（未設定時は 403）
- 回帰: `python test_store_isolation.py`

## 店長向けコマンド早見

| コマンド | 内容 |
|----------|------|
| `店舗作成 青山店` | 新規店舗＋招待コード。自分が店長 |
| `店長登録 CODE` | 既存コードへ店長参加（横断エスカレーション不可） |
| `時給 太郎 1200` | 自店スタッフの時給 |
| `人件費予算 200000` | 自店の月次予算 |
| `給与 今月` | 自店の給与見込み（店長） |
| `給与確定 9月` | 自店ロック（振込なし） |
