# SaaS 店舗オンボーディング（PoC・正直版）

マルチテナント隔離の前提: **A店の店長は B店のスタッフ／時給／給与／予算を見られない・触れない**。  
データは `stores.json` 上で `store_id` 単位に分かれ、LINE 操作は常に `user_index` → 所属店舗のみを参照します。

## PoC の現実（共有公式アカウント）

| 今（PoC） | 将来（本番 SaaS） |
|-----------|-------------------|
| **1つの shared Official Account** ＋ **店舗ごと招待コード** | 店舗ごと（または加盟店ごと）に Messaging API チャネル |
| スタッフは同じ友だち追加 URL／QR → 「登録 CODE」で店舗に紐付け | 友だち追加時点でチャネル＝店舗が分離 |
| 店長は「店舗作成 店名」で自分の店舗＋招待コードを発行 | 管理コンソール／課金テナントと OA を紐付け |

PoC でも **アプリ層の店舗隔離は必須**（本ディレクトリの `stores.py` / webhook が担当）。  
チャネル共有は「届くトークが同じ箱」なだけで、給与・スタッフ名簿は店舗境界を越えない実装にしています。

## 店長の手順（LINE）

1. **公式アカウントを友だち追加**（共有 OA の友だち追加 URL／QR）
2. **店舗を開設**  
   ```
   店舗作成 青山店
   ```  
   → 返信に `招待コード`（例: `K7MP2Q`）と店舗IDが返る。あなたが店長になる。
3. **スタッフを招待**  
   - 友だち追加 URL／QR を渡す  
   - あわせて招待コードを口頭／紙／チャットで渡す  
   - スタッフは: `登録 K7MP2Q 太郎`
4. **時給・交通費・予算**（店長コマンド）  
   ```
   時給 太郎 1200
   交通費 太郎 500
   人件費予算 200000
   ```
5. **シフト／給与**  
   ```
   シフト3案作って
   確定 希望
   給与 今月
   給与確定 9月
   ```

既存デモ店舗に参加する場合のみ: `店長登録 DEMO01`  
※ すでに別店舗の店長なら、他店への店長登録は **拒否**（店舗隔離）。

## スタッフの手順

1. 公式を友だち追加  
2. `登録 <招待コード> <表示名>`  
3. `希望休 日曜` / `自分のシフト` / （自分の）`給与 今月`

スタッフは **同僚の時給・給与明細を見られません**（店長のみ）。

## 隔離の要点（実装）

- すべての読取／書込は `get_store_for_user(userId)` の `store_id` にスコープ
- 人名解決（`find_worker_id`）も **その店舗の members のみ**
- `GET /stores` は全店舗一覧のため **`LINE_STORES_ADMIN_TOKEN` + `X-Admin-Token` 必須**（未設定時は 403）
- 回帰: `python test_store_isolation.py`

## 店長向けコマンド早見

| コマンド | 内容 |
|----------|------|
| `店舗作成 青山店` | 新規店舗＋招待コード。自分が店長 |
| `店長登録 CODE` | 既存コードへ店長参加（横断エスカレーション不可） |
| `時給 太郎 1200` | 自店スタッフの時給 |
| `人件費予算 200000` | 自店の月次予算 |
| `給与 今月` | 自店の給与見込み（店長） |
| `給与確定 9月` | 自店ロック（振込なし） |
