# 解約・返金ポリシー（販売版ドラフト）

> 本書は販売版 PoC のドラフトです。法的助言ではありません。実運用前に店舗オーナーと専門家が確認してください。

## 1. 解約
店長は「申し込む フリー」またはサポート窓口への連絡により、有料プランを解約できます。解約手続き後、現在の請求期間の終了をもって有料機能が停止します。

## 2. 期限切れ・支払い失敗
トライアル終了、更新失敗、または支払い不能の場合、有料機能（シフト3案、人件費最適化、給与/CSV、QAOA比較、複数店舗など）は利用できなくなります。

## 3. データの取り扱い（重要）
解約・期限切れ・支払い失敗のいずれの場合も、**店舗・スタッフ・シフト・給与（見込み/明細/CSV）データは削除しません。** 機能のみが制限されます。再申し込み後、保存済みデータを引き続き利用できます。

## 4. 返金
月額課金の日割り返金は原則行いません（プロバイダの規定および個別契約による）。誤課金・重複課金が確認できた場合は、決済プロバイダ経由で返金対応します。

## 5. 決済手段
LINE Mini App の IAP は都度課金（consumable）のみのため、本サービスの定期プランには使用しません。外部 Payment Provider（Checkout + webhook）で契約を店舗（store_id）に紐付けます。
